SPECIAL COMPONENTS
──────────────────────────────────────────────────────────────

ParticleBackground:
  <canvas> element filling the entire hero section.
  Renders 80 floating particles (dots) that move slowly and
  draw connecting lines between nearby particles.
  Uses requestAnimationFrame for smooth animation.
  Responds to window resize.

TypingAnimation:
  Displays text one character at a time (typewriter effect).
  Props: text (string), speed (ms per char, default 100ms).
  Loops: after finishing, waits 2s then clears and retypes.

SkillBadge:
  Shows skill name as a badge.
  On hover: shows a small progress bar indicating the level %.
  Props: name, level (0–100), delay (for staggered animation).

Timeline:
  Vertical timeline component.
  Each item: colored dot (blue for education, green for experience),
  connecting vertical line, title, org, location, dates,
  description paragraph, skill tags as badges.

ProjectCard:
  Card with: image (aspect-video), gradient overlay on image,
  title, description, tech badges, GitHub icon button.
  Entire card is clickable → opens ProjectModal.

ProjectModal:
  Full-screen dialog showing all project details:
  image, title, long description, features (bulleted list),
  challenges (bulleted list), tech stack badges,
  "View on GitHub" button.

BlogCard:
  Card with: tags, title, excerpt, date, read-time.
  Clickable → opens inline blog post modal.

ContactForm:
  React Hook Form + Zod validation.
  Submits to POST /api/contact via TanStack Query mutation.
  Shows loading state, success toast, error toast.

ThemeProvider + ThemeToggle:
  localStorage-synced dark/light mode toggle.
  Toggles "dark" class on document.documentElement.
